# O.Martynenko.pro

Многостраничный статический сайт-визитка для цифровых решений и ИИ-автоматизаций: разработка сайтов, приложений, презентаций, ботов и ИИ-ассистентов.

## Описание

Сайт презентует услуги разработчика **Ольги Мартыненко** (специалист полного цикла) и два готовых продукта:

- **ИИ-агент CAI** (`cai.html`) — автоматизация документооборота: разбор почты, маршрутизация договоров, отчёты, контроль дедлайнов.
- **ИИ-бот для поиска работы** (`bot.html`) — бесплатный Telegram-бот: поиск вакансий (HH.ru, GeekJob, Trudvsem), Match Score, cover-письма, напоминания. Премиум-тарифы в Telegram Stars.

Отдельная промо-страница (`promo.html`) используется для быстрых превью и рекламных вставок.

## Стек

- HTML5 (семантическая разметка)
- CSS — встроенный в страницы (без внешних таблиц)
- JavaScript — встроенный (анимации, IntersectionObserver)

## Схема деплоя

```
git push (my-site) → GitHub Actions (deploy.yml) → публичный репозиторий omartynenko-pro.github.io → GitHub Pages
```

Workflow `deploy.yml`:

1. Триггеры: `push` в ветку `main` и ручной запуск `workflow_dispatch`.
2. Клонирует публичный репозиторий через `PAGES_DEPLOY_TOKEN`.
3. Копирует страницы (`index.html`, `cai.html`, `promo.html`, `bot.html`), `README.md` и картинки (`hero.jpg`, `og-image.jpg`, `bot-hero.jpg`).
4. Коммитит и пушит в публичный репозиторий.

## Как обновлять сайт

1. Внести правки в файлы в рабочей папке (`my-siteOM`).
2. `git add .`
3. `git commit -m "описание изменений"`
4. `git push origin main`

После пуша GitHub Actions автоматически обновит публичный сайт (обычно в течение 1–2 минут).
