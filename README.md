# O.Martynenko.pro

Многостраничный статический сайт-визитка для цифровых решений и ИИ-автоматизаций: разработка сайтов, приложений, презентаций, ботов и ИИ-ассистентов.

## Описание

Сайт презентует услуги разработчика **Ольги Мартыненко** (специалист полного цикла), два готовых продукта и личную презентацию:

- **ИИ-агент CAI** (`cai.html`) — автоматизация документооборота: разбор почты, маршрутизация договоров, отчёты, контроль дедлайнов.
- **Интерфейс CAI** (`cai-app.html`) — тур по 27 экранам программы, презентация документооборота и расчёт ROI во встроенном PDF-просмотрщике.
- **ИИ-бот для поиска работы** (`bot.html`) — бесплатный Telegram-бот: поиск вакансий (HH.ru, GeekJob, Trudvsem), Match Score, cover-письма, напоминания. Премиум-тарифы в Telegram Stars.
- **Презентация O.Martynenko.pro** (`pdfs/martynenko-presentation.pdf`) — 9 слайдов о себе, опыте, цифровом стеке и форматах работы; ссылка есть в шапке главной и в блоке «Мои разработки».

Отдельная промо-страница (`promo.html`) используется для быстрых превью и рекламных вставок.

Главная страница (`index.html`) устроена по секциям: «Ваш универсальный разработчик», «Полное погружение в ваш проект», «Мои разработки» — дальше услуги, цифровой стек (в том числе Python) и контакты.

В шапке всех страниц — кнопка **«Связаться»** с выбором: почта или Max. Верхняя панель и нижний блок на всех страницах оформлены как стеклянные плашки с оттенком под палитру страницы. На промо-странице в карточке дополнительно есть дропдаун **«Написать мне»**.

## Схема деплоя

```
git push (my-site) → GitHub Actions (deploy.yml) → публичный репозиторий omartynenko-pro.github.io → GitHub Pages
```

Workflow `deploy.yml`:

1. Триггеры: `push` в ветку `main` и ручной запуск `workflow_dispatch`.
2. Клонирует публичный репозиторий через `PAGES_DEPLOY_TOKEN`.
3. Копирует страницы (`index.html`, `cai.html`, `cai-app.html`, `promo.html`, `bot.html`), `README.md`, картинки (`hero.jpg`, `og-image.jpg`, `bot-hero.jpg`, `favicon.svg`), а также папки `pdfjs/`, `pdfs/` и `cai-screenshots/`.
4. Коммитит и пушит в публичный репозиторий.

## Как обновлять сайт

1. Внести правки в файлы в рабочей папке (`my-siteOM`).
2. `git add .`
3. `git commit -m "описание изменений"`
4. `git push origin main`

После пуша GitHub Actions автоматически обновит публичный сайт (обычно в течение 1–2 минут).
